# Автотюнинг71

Лендинг студии «Автотюнинг71» (Мастерская автозвука 71 / King Sound Тула), р.п. Первомайский, Пролетарская ул., 16/2.

- Факты (услуги, контакты, режим, отзывы) — только с официальной карточки Яндекс Карт (https://yandex.ru/maps/org/avtotyuning71/93967381613/), сайта masterskaja-avtozvuka71.clients.site и группы vk.com/king_sound_tula.
- Цены и отзывы редактируются в `data.js`. Цены не опубликованы — показывается «цены уточняйте по телефону».
- Изображения в `assets/images.js` (webp, data URI) — сгенерированные иллюстрации, не фото работ.
