# Автотюнинг71

Статический сайт для «Мастерской автозвука 71» (King Sound Тула), р.п. Первомайский, Пролетарская ул., 16/2.

Все данные (услуги, контакты, режим, отзывы) взяты с официальной карточки организации в Яндекс Бизнесе (masterskaja-avtozvuka71.clients.site) и группы ВК (vk.com/king_sound_tula). Цены не опубликованы — на сайте указано «цены уточняйте по телефону».
